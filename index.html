A home SOC built to watch, detect, and triage — from scratch, on my own hardware.

A fully local security operations lab: a segmented pfSense perimeter feeding an Ubuntu defender host and a Kali attack box, an n8n automation layer, and a standalone ELK stack going in for centralized log analysis. No cloud dependency this round — every piece runs on hardware I control end to end.

The Stack

Components

Four VMs plus the host, each with a specific job in the lab.

⛨

pfSense

Perimeter firewall and VLAN segmentation, separating the guest network from the host.

🖥

Ubuntu Desktop — Defender

Vulnerable-by-design target: DVWA and Juice Shop, sitting inside the guest VLAN for attack/detect exercises.

⚔

Kali Desktop VM

Attacker box for running exercises against the defender host and generating the traffic ELK will later ingest.

⚙

n8n VM

Automation layer for the lab. Currently idle, pending re-integration once ELK is up.
