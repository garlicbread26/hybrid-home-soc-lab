Hybrid Home SOC Lab

A hybrid cybersecurity home lab designed to simulate a small Security Operations Center (SOC) environment using on-premises virtualization, network security, cloud infrastructure, endpoint telemetry, SIEM, detection engineering, SOC investigation and automation.

Lab Architecture

  • Windows Physical Host
  • VMware Workstation Pro
  • pfSense Firewall
  • Suricata IDS/IPS
  • pfBlockerNG
  • Ubuntu Desktop Test/Defender VM
  • Oracle Cloud Infrastructure (OCI)
  • Wazuh SIEM
  • Windows Sysmon
  • Wazuh Agent
  • Kali Linux via Docker
  • Tailscale VPN
